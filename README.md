# AR 5th Birthday Card Project

A themed Augmented Reality web application built using A-Frame and AR.js for an interactive 5-year-old girl's birthday greeting card scene.

## Features
- **Hiro Marker Scene:** Features a styled platform containing multiple primitives (a cylinder, a gift box, and two balloons) alongside a custom text label.
- **Animations:** Includes smooth continuous rotation and bobbing position keyframe animations on the balloon elements.
- **Interactive Components:** Features a custom color-changing component on the gift box and a custom `tap-grow` scaling component on the 3D birthday cake model.
- **Status Banner:** Dynamic HTML indicator that updates its color and text when the Hiro marker is found or lost.
